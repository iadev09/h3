# h3-datagram-forked

The HTTP Datagram extension in the
[h3-forked family](https://github.com/iadev09/h3/tree/forked/0.0.8), depending on
`h3-forked` rather than the upstream `h3` package.

Add the crates.io dependency:

```toml
[dependencies]
h3-datagram = { package = "h3-datagram-forked", version = "0.0.3" }
```

The Rust crate name remains `h3_datagram`. For protocol details and usage, see
the [upstream documentation](https://github.com/hyperium/h3/tree/master/h3-datagram).
For provenance and maintenance policy, see the
[fork README](https://github.com/iadev09/h3/blob/forked/0.0.8/README.md).

This is an independent, experimental fork, not an official Hyperium release.
